# 🕌 أبطال الطهارة والصلاة

موقع عربي تفاعلي مرح لتعليم الأطفال والناشئة الوضوء والصلاة.

## التشغيل محلياً
افتح ملف `index.html` مباشرة في أي متصفح — يعمل بدون سيرفر وبدون إنترنت (ما عدا الخط أول مرة).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع ملف `index.html`.
2. من Settings ← Pages ← اختر Branch: `main` والمجلد `/root`.
3. سيتاح الموقع على: `https://username.github.io/repo-name/`

## الأقسام
- 💧 الوضوء خطوة بخطوة + شريط تقدم
- 🙏 محاكاة الصلوات الخمس وحركاتها وأذكارها
- ⚠️ صح مقابل خطأ
- 🏆 كويز + احتفال Confetti
- 🎓 شهادة باسم الطفل قابلة للطباعة
